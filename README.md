本项目是一个纯前端、零依赖的个人生活助理。将“健康记录（饮食/睡眠/运动）”、“AI 行为分析”与“日程落地（.ics 导出）”三个模块深度融合。拒绝制造焦虑，只提供可执行的反馈。

> ⚠️ **当前状态：Beta 测试版 / 开题演示版**
> 核心链路已打通，但部分 UI 细节仍在打磨，AI 接口适配层正在持续扩展中。

## 核心特性

- 🧩 **单文件集成架构**：躯干（记录 UI）与大脑（AI 决策引擎）集成于单一 HTML 文件中，跨模块数据无缝流转。
- 🤖 **AI 双轨引擎**：支持直连标准 OpenAI 兼容接口（如 DeepSeek），当网络异常或断网时，自动无缝降级到内置的离线规则引擎（Mock）。演示永不翻车。
- 🛡️ **三条防幻觉硬规则**：
  - **缺失 ≠ 0**：没记录的日子不按 0 计算，不进均值，不判未达标。
  - **异常值排除**：超范围输入（如 400 分钟运动）标红警告且不参与统计。
  - **数据不足不作因果**：有效记录 < 3 天时，只描述现象，禁止“因为…所以…”的瞎编。
- 📅 **跨应用数据流转**：AI 生成的“周一 17:30 去跑步”等自然语言建议，可一键转码为严格的 JSON 数组，直接投喂给“日程助手”导出 iPhone 原生日历。
- 🔒 **隐私绝对隔离**：无后端、无数据库。所有健康记录、日程配置、API Key 均保存在浏览器 LocalStorage。

## 使用流程

1. **记录生活**：在首页记录今日的喝水、饮食、睡眠或运动。
2. **AI 洞察**：进入「运动」页，点击生成解释。系统会基于底层统计算法给出带有数据边界的分析。
3. **行为闭环**：点击生成本周行动建议，若执行受挫（如太累、没时间），提交反馈，AI 会动态降级调整计划。
4. **日程落地**：点击「复制日程 JSON」 -> 切换到「日程」Tab（嵌入的网页 1）-> 粘贴 JSON -> 导出 `.ics` 文件 -> 导入 iPhone 日历。

## 数据与安全

- 本网页**不发**任何未经许可的网络请求。
- 所有的 API 调用（点击生成解释/建议时）仅将必要的统计数据（不含个人隐私明细）发送给所填写的 API 端点。
- 数据存储于浏览器 `localStorage`，清除浏览器缓存或更换域名将导致数据丢失，请善用「备份数据」功能。

## 开发者说明与边界

- **iframe 限制**：若在本地直接双击打开 (`file://`)，浏览器安全策略可能拦截 iframe 内的跨域请求。建议使用 `python -m http.server 8000` 或部署至 Vercel/GitHub Pages 后使用。
- **接口扩展**：默认请求 DeepSeek 官方端点。未来计划在设置中开放 `Base URL` 与 `Model` 自定义，以适配校园网关或本地 Ollama。
- **已知限制**：
  - 行动建议目前只输出运动项，睡眠与饮水暂不生成行动。
  - 单用户，未做多账号。
  - 统计周期为自然周（7 天切分），跨周的部分按不完整周列出。
