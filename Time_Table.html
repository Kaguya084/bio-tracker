暂存的原文

添加事项 手动录入一条日程

填好下面各项，点「添加 / 批量生成」把它放进备忘录（还不会进日历——要到顶部「导出 ics」才会同步到 iPhone）。标题写多行可一次生成多条。
空着的「年 / 月 / 日」是跨天结束日期：活动连着好几天才填（填了会按整天横条显示），单日留空；选了「重复」才需要填「重复截止日」（含当天）。
添加后出现在下方「全部事项」；改完去顶部「导出 ics」才会同步到 iPhone 日历。

全部事项

搜索时忽略时间范围，在全部事项里找。
已选 0 条
分类怎么选：DDL = 有截止、要交东西的；活动 = 要到场参加的；个人 = 只跟自己有关的私事。
分错类会进不同的 ics 文件 —— 在 iPhone 里就是不同的日历，提醒时机也不一样（各自提前多久可在下面「默认提醒时间」里改）。
改完记得导出 —— 顶部出现「日历待更新」就说明改动还没同步到 iPhone。

数据备份 / 迁移

学期设置 设置第一周的周一

设置后，日程表会据此计算「第 X 周」以及对应的真实年月日。
数据存在浏览器本地，按网址隔离 —— 换网址（比如换到 GitHub Pages）就等于换了一份空数据。
换之前先「复制全部数据」，到新地址「粘贴恢复」即可。
会清掉课表、事项、基线记录、汇总标记 —— 建议先复制备份。清完回到空状态，可重新导入。

老数据修复

用旧版网页存过课表 / 事项，升级后可能因字段缺失导致「日程表」打不开 （典型：旧版课程用 end 存结束时刻，新版改成了 endT，缺失 endT 会让周视图 mins(undefined) 崩溃）。
点下面按钮：扫描本机课表与事项，给缺失字段补上安全默认值，并写回本机（不影响现有内容）。

默认提醒时间 导出 ics 时，没单独设提醒的事项按这里

每种类型最多两条默认提醒（提前多少分钟）。0 = 时间发生时，留空 = 不设这条；1440 = 1 天，60 = 1 小时。
